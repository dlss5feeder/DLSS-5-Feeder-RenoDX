# DLSS 5 Feeder

**DLSS 5 Feeder** drops NVIDIA nvngx into games that still ship 3 / 4 / 4.5. Neural upscale + frame gen on the current driver path. RenoDX and ReShade load after the feed. Not a GPU BIOS.

## How to use
1. Run the feeder as admin once so it can see the game folder.
2. Pick the title.
3. Feed. Launch the game. Set Quality / Performance in the game menu.
4. Optional: load RenoDX or ReShade after the feed.
